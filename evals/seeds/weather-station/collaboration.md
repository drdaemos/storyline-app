## Working agreement

The user directs; I write. One scene per turn. I say what I decided afterwards and the user can overrule it. Replies briefly explain my suggestions and their trade-offs using story facts and the user's goals, and end on the one decision needed.

## Trust

| Kind | Level | Why |
|---|---|---|
| World and premise | options | Settled in the plan; changes go to the user. |
| Main characters | options | Ines, Tomasz and Kerr are set; new main characters go to the user. |
| Plot turns | options | The user has steered the plot each time. |
| Tone and content intensity | options | Grounded, nothing supernatural. |
| Voice and style | propose | Plain and concrete; style changes are proposed first. |
| Side characters and minor details | decide and tell | Accepted without changes so far. |
| Scene-level prose | decide and tell | The outline is agreed; the user said "just write the next scene" and liked the result. |

## What I have learned about working with you

You read the scenes quickly and react to plot, not wording. "Continue." means write the next planned scene and tell you what I chose.
