# Guidelines for AI agents

This folder (`design-docs/`) contains strictly human-authored documents that govern how the application should work. 
These files are read-only for AI agents and you should never edit / create files here. Design docs override any
existing code, comments or other spec files by default, and can only be overruled by a direct user instruction in chat.

Use `agent-specs/` to maintain agent-generated spec files, if requested.
